# Akshara Jain | Portfolio

My personal portfolio website, built with plain HTML and CSS.

It covers who I am, what I can do, my skills, the projects I've built, my background and how to reach me.

## Sections

- **Hero**: intro with hills and clouds
- **About**: a short hello
- **What I can do**: web apps, data and ML, shipping projects online
- **Skills**: languages, web, ML & AI, tools
- **Projects**: Career Compass AI, Movie Recommendation System, DermAI, Wanderlust
- **Background**: education, TCS, Infosys Springboard internship, certifications
- **Contact**: email and social links

## Built with

- HTML5
- CSS3 (flexbox, CSS variables, responsive layout)
- Google Fonts: Montserrat, Merriweather and Sacramento

## Run it locally

1. Clone the repo
   ```
   git clone https://github.com/Akshara-codes/Portfolio.git
   ```
2. Open `index.html` in your browser.

No build step or dependencies needed.
